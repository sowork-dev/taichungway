# 視覺設計 Review

日期：2026-10-27。範圍：啟臣聊一下、城市冒險、泡泡 PK、入口站、沾福氣、你是哪一味、四格漫畫、對開支票本、聲音明信片。

## 結論

客戶喜歡的是**城市冒險**：有角色、能走動、點了有回應。其他頁面的共同問題是「像文章，不像遊戲」：字太多、可點的東西太少、回饋太小。這輪改動的方向是把城市冒險的遊戲感擴展到全站，並套用同一套藍色遊戲介面。

## 診斷（改動前）

| 問題 | 出現位置 |
|---|---|
| 說明文字比互動多：每頁都有 3–6 段聲明、副標、說明 | 全站，尤其三個創作室、聊天頁 |
| 主要操作是「填表單」：textarea、清單、下拉 | 四格漫畫、支票本、聲音明信片 |
| 回饋小：按了只有文字變色 | 全站 |
| 兩套視覺互不相識：白底編輯風 vs 深藍遊戲風 | 入口站與創作室 vs 城市冒險、泡泡 PK |
| 角色只存在於城市冒險 | 聊天頁、入口站沒有人物 |
| 沒有「進度／獎勵」語言 | 全站 |

## 設計原則

1. **三秒規則**：主畫面只放圖示、大按鈕、一個短標題；其餘進「ⓘ 說明」。
2. **用手玩，不是用眼讀**：選擇一律做成大圖磚／大按鈕；輸入框是次要路徑。
3. **每個動作都有回饋**：按下去有位移、有彈出、有星星或彩紙。
4. **同一套零件**：按鈕、面板、徽章、緞帶、星星、愛心、進度條（`gamekit.css`）。
5. **品牌**：主色 `#1A63C8`（官網深藍 `#004C9F` 作陰影與邊）；愛心用旗幟紅；其餘為白與淡藍。
6. **聲明不能少**：非官方、非施政成果、來源仍在畫面或匯出圖卡中，只是收起來，不刪。

## 參考圖的對應

參考圖是手遊 UI 套件：徽章、粗外框按鈕、緞帶標題、星級、愛心、貨幣、圓形圖示鈕。這裡把木頭與草的材質換成藍色與白色，保留「粗邊框、頂部高光、底部厚度、按下位移」。

## 本輪已做

- 共用零件：`platform/packages/ui/src/gamekit.css`（公開站用 `public/gamekit.css`，測試確保兩份相同）與 `gamekit.tsx`（星星、愛心、貨幣、八個遊戲圖示）。
- 入口站：改成關卡選擇畫面；城市冒險為大卡，聊天與泡泡 PK 已列入。
- 沾福氣：改成可蓄力的大金幣＋進度環，結果頁有三星與彩紙。
- 你是哪一味：進度條、2×2 大答案磚、結果頁三星。
- 四格漫畫／支票本／聲音明信片：外殼改為遊戲舞台，各自加入進度星、圖示選擇與完成動畫（見各自 commit）。
- 啟臣聊一下：人偶、打字機效果、圖示快捷鈕，聲明收進說明。
- 城市冒險：人偶點擊會跳、揮手、說話；路人會轉向招手；完成任務有彩紙。

## 仍待處理

- 全部畫面只用自動化瀏覽器截圖驗證，沒有用手機實機試過手感與動畫。
- 人偶與圖示是自繪簡單向量，正式版需要設計師重畫，並可擴成多種表情。
- 沒有音效與觸覺設計（目前僅在少數互動使用震動）。
- 城市冒險地圖仍是單一藍色，樹與路的辨識度偏低；若客戶要保留原風格，建議回到冷綠色地面。
- 泡泡 PK 的對戰畫面沒有套用新元件（血量、勝利星星、對手頭像）。
- 入口站的三個主遊戲連結使用正式網域，需確認部署後的實際網址。

## 風格第二版（Pop）

參考圖是 Memphis 風格的海報：傾斜的立體網點大字、波浪色塊、星芒貼紙。全站頁面統一為這個風格：米黃底、青藍與國旗紅的波浪色塊、白色面板加粗黑邊與硬陰影、頁首為立體大標題。城市冒險的地圖畫面維持原樣，只換外框與按鈕。

- 共用：`gamekit.css` 的 `.gk-3d`（立體網點標題）、`.gk-popbg`、`.gk-sparkle`、`.gk-sticker`、`.gk-tile--*`。
- 公開站頁面（聊天、城市冒險、泡泡 PK）使用 `public/pop.css` 與 `public/gamekit.css`。
- 立體標題的粗細取決於裝置字型，建議用 iPhone / 新款 Android 實機確認。
