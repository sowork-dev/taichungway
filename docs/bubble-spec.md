# 臺中泡泡 PK 互動規格 v1

狀態：草案，待確認「待決定」一節。範圍：`public/bubble.html`、`play.js`、`play.css`、`pop.css`；遊戲規則引擎 `bubble-core.js` 與即時後端 `server/play-server.cjs` 的**權威規則不變**。
沿用的原則：不補假人、不做政策閱讀門檻、客戶端只送操作意圖、伺服器維護位置／碰撞／計分、少字、進度只存本機、不做聲音（先不做）。

## 1. 現況與問題

- 規則：9×13 格、兩人對戰、放水球、十字水波、困住對手得 1 分、先 3 分或 60 秒；沒人時單人練習（清街區 +1，無結束時間、無目標）。
- 問題：
  1. **沒人在線就沒得玩**，而規則禁止假人；練習模式沒有目標，玩 1 分鐘就膩。
  2. 沒有新手引導；第一次看到畫面不知道要做什麼。
  3. 勝負畫面平淡；沒有「再玩一次」的理由；沒有分享。
  4. 邀請朋友的流程不明顯（等人時畫面是空的）。

## 2. 參考的遊戲設計（只借機制，不用任何美術、名稱或程式）

| 參考 | 借用的設計 | 用在哪裡 |
|---|---|---|
| Bomberman 類（規則本來就參考格子水球） | 單人「清關＋計時＋星級」 | 單人挑戰（第 3 節） |
| Wordle | **每天同一個挑戰**、不需帳號、用表情方塊分享結果、一天只有一次的「儀式感」 | 今日挑戰與分享（第 4 節） |
| 寶可夢圖鑑 | 蒐集冊、「再 N 個集滿」 | 街區點亮冊（第 5 節） |
| 瑪利歐賽車／格鬥遊戲 | 一戰結束立刻「再戰」、勝負大標題 | 勝負畫面（第 6 節） |

## 3. 單人挑戰（解決「沒人就沒得玩」，不需要假人）

沿用現有單人練習，**加上目標與星級**，仍然沒有對手、沒有計時結束、不改引擎規則。

- 目標：清光 16 個街區。
- 星級（本機計算，個人紀錄，不上傳、不排行）：
  - ★ 清光全部；
  - ★★ 且 60 秒內；
  - ★★★ 且 45 秒內，並且沒有被自己的水波困住。
- 顯示：頂部「n / 16 街區」進度條；完成時大標題「清光！」＋星星＋「再挑戰」「找朋友 PK」兩個按鈕。
- 計算來源：引擎快照的 `destroy` 事件與 `trapped` 事件，客戶端累計；本機最佳時間存 localStorage。

## 4. 今日挑戰（每天一個，全站相同，不需後端）

用日期決定當日目標（固定清單輪替），例如：

| 目標 | 判斷（皆可由事件計算） |
|---|---|
| 60 秒內清光 | 時間 |
| 只用 8 顆水球清光 | 放置次數 |
| 不被困住清光 | 沒有 `trapped` |
| 一顆水波連鎖炸 2 個以上街區 | 同一波 `destroy` ≥ 2 |

- 一天可重玩，記錄當日最佳；完成後出現「分享結果」：產生像 `泡泡 PK 今日挑戰 ★★☆ ⬛⬛🟦🟦…` 的純文字（方塊數＝清掉的街區），**不含暱稱與個資**。
- 沒有連續簽到、沒有斷簽懲罰、沒有倒數壓力。

## 5. 街區點亮冊（收集與回訪）

- 15 個街區代表 15 個政策主題（引擎已有每個街區的 `topicId` 與簡短標籤）。清掉對應街區 → 該主題「點亮」。
- 冊頁：15 格，顯示 n / 15；點亮格可點開看主題名稱與既有公開資料卡連結。
- **文案固定**：「遊戲清格、點亮、分數都不是政策施行、預算或成效」，沿用現有聲明。
- 存本機 localStorage（`taichung-bubble-v1`，格式驗證失敗整份不採用），可清除。

## 6. 新手引導（10 秒內學會）

- 第一次進入：三格示範動畫「走 → 放水球 → 躲」，各 ≤4 字，可略過。
- 引導任務：「放一顆水球，炸開一個街區」（完成給 1 次小慶祝），之後才顯示完整目標。
- 之後永遠只顯示一行操作提示（沿用現有 `左手走 右手放`）。

## 7. 對戰與社交

- 規則不變（真人、伺服器判定）。
- **等朋友畫面**：開新場後顯示大房號、「複製邀請」「分享」按鈕與兩個人偶輪廓（朋友加入時人偶亮起）；等待時可先單人挑戰，朋友加入即切到對戰（沿用現有行為）。
- **勝負畫面**：立體大標題「勝！／敗…／平手」＋雙方分數＋「再戰」大按鈕（雙方都按才開始，沿用現有規則）＋「分享戰績」（純文字，不含暱稱）。
- 不做排行榜、不做帳號、不做永久戰績。

## 8. 回饋（不加聲音）

- 街區被炸開：碎裂與彈出小星。
- 被困住：氣泡搖晃＋裝置震動（支援才有）；連鎖：畫面輕震。
- 險些被炸：邊緣閃一下「險！」。
- `prefers-reduced-motion`：關閉震動與碎裂動畫，保留結果與提示文字。

## 9. 文字預算與無障礙

- 對戰畫面：不超過 ≤8 字的提示；說明、來源、聲明收進「說明」。
- 搖桿與水球按鈕 ≥56px；鍵盤（方向鍵／WASD＋空白）與觸控都能完成一輪；點地走路保留。
- 大字模式下 HUD 不遮住棋盤。

## 10. 驗收標準

1. 新玩家從開啟到放第一顆水球 ≤10 秒（人工計時 5 人）。
2. 單人挑戰可完成並得到星級；星級判斷以固定事件序列做單元測試。
3. 今日挑戰：同一天任何裝置得到相同目標（以日期字串測試）；分享文字不含暱稱與房號。
4. 街區冊儲存格式驗證失敗整份不採用（測試）；冊頁與分享文字不含「投票／支持／推薦」。
5. 既有 `bubble-core`、`play-server` 測試不退步；不改動伺服器權威規則。

## 11. 實作切分

1. 純函式模組 `public/bubble-meta.js`（星級、今日目標、街區冊、序列化），含測試。
2. `play.js`：事件累計、進度條、挑戰結算畫面。
3. 新手引導與等朋友畫面。
4. 街區冊頁與分享文字。
5. 勝負畫面與回饋動畫。
6. 實機（含雙人）與計時驗收。
