# 遊戲優先重做：線上加入與同場 PK

狀態：已依使用者選定③實作「同城搶送」並跑通本機兩端流程。本文件是玩法規格；正式部署狀態以發布回讀與實際公開驗收為準，不以本機測試冒充上線。

## 使用者已明確指出

- 目前文字太多、資訊很煩、操作不像遊戲，不想先讀懂政策。
- 以《議場大亂鬥》的直覺操作與參與方式為主要參考，不再混搭更多遊戲。
- 要有真人線上互相加入的機制，兩人能 PK。
- 原汁原味的臺中地景元素，以及原先完整提供的政策資料，仍須保留。

## 新版主要流程提案

1. 一鍵開始，直接進可操作的遊戲場景；不先讀政策、做測驗或填房號。
2. 同時開放線上大廳／可加入場次。人數與狀態來自實際連線，不補假人。
3. 無人時先玩可實際操作的單人練習，等待不中斷；其他網友一鍵加入，雙方看見彼此角色。
4. 第二人到場後開始公平的新回合，不把原本單人累積分數帶入雙人競賽。
5. 核心動作只有移動、搶補給、送給市民；即時顯示持有物、目的地、送達效果與雙方比分。
6. 到時結算並可再戰，也保留分享連結邀請朋友的次要入口。

這是同圖、同資源、同回合的動作 PK，不能用既有各自四選一答題頁替代。不得把練習 NPC 冒充真人對手。

## 資訊與政策

主畫面以角色、目標、方向、補給與比分解釋玩法，不用長說明書。政策轉成任務背景與可理解的道具語意；全文、原文出處及提供文件性質由玩家主動點開，不能成為開始玩的門檻。完整來源庫保留，不刪除已提供資料。

地景為原創臺中意象，標示非比例。AI 分身／非本人即時回覆的必要揭露仍保留，但不再重複用大段文字阻斷動作。遊戲效果不是施政成效或政治支持度。

## 執行前固定的驗收邊界

- 首次玩家不讀長文就能完成第一個送達動作；十秒內知道怎麼玩是待驗證的可用性目標，不是已量測成果。
- 兩個獨立瀏覽器從公開入口找到並加入同一場，不強迫事先交換房號；邀請連結也須可用。
- 兩端看見對方移動、補給被誰拿到、送達與相同比分；伺服器處理資源歸屬與得分，不能接受客戶端任意加分。
- 斷線、退出、重複送達、同時搶同一物件都不製造假分數或幽靈勝利。
- 需正式公開部署後再驗收上述完整流程；本機 READY、功能測試或房間畫面不算使用者已能試玩。
