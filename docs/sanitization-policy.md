# 公開版本的邊界

此 repo 以全新公開提交歷史發佈，不攜帶內部工作目錄或部署歷史。

## 保留

- 手機網頁、原創人偶 SVG、檢索引擎。
- 已公開政策資料與逐筆來源連結。
- 可執行的單元測試、瀏覽器驗收與公開使用文件。

## 不包含

- 內部部署腳本、VM 位址、管理帳號、SSH 金鑰路徑。
- DNS／雲端帳號、憑證、金鑰、執行環境設定。
- 私人對話、Slack 討論、客戶檔案、內部研究流程或驗收環境記錄。

公開政策資料中的人物姓名及體驗網站網址是本專案的必要公開內容，不應誤認為候選人授權。測試中的電話形狀輸入是用來測試個資防護的合成測試值。

公開程式碼不會自動部署到體驗網站。後續如新增 API 或模型，必須重新檢查權限、費用控制、隱私、來源邊界與安全測試。
