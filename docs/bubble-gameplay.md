# 單屏水球版：已選定的重做規格

使用者批准以《爆爆王》的格子水球互動為主要參考。這不是再替搶送版加一段說明；主要操作與視覺都改成可直接辨識的格子競技場。

## 必要主循環

- 一個完整可見的9×13格場地，不跟隨鏡頭、不必找對手在哪。
- 大角色、左手上下左右移動、右手唯一動作「水球」。桌機方向鍵／WASD與空白鍵對應同一操作。
- 水球短倒數後向上下左右散開，阻擋物會截住水波；先給看得到的十字範圍，再呈現清格／泡泡效果。
- 清除街區開出路線。困住對手得1分，先3分勝；60秒到時比得分。自己也要躲水波，但不因自困送分。
- 無人時可實際移動、放球、清格練習，不補假人。第二位真人加入後全場重設、倒數開賽。
- 保留大廳、真實人數、分享連結、兩端同步、雙方再戰與誠實退場。

## 技術與回歸

新 BubbleCore 與舊 ArenaCore 分離。伺服器預設使用新核心；舊核心只供程式內回歸注入，不能由公開輸入任意切換模式。沿用已驗證的token綁定、同步撤銷玩家、500ms關閉握手上限、64KiB慢讀佇列限制、逾時清除與同源WSS。

驗收必須透過真實瀏覽器操作與公開API意圖：放球、正常移動、清格開路、泡泡命中、三分勝負、重賽、離房。不可用測試傳送或客戶端直接加分替代。手機多點觸控與全場可見另驗；自動化不等於真人上手測試。
