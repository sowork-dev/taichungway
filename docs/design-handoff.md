# 台中味設計與前端交接

## 目前狀態

`platform/` 已擴充為入口＋五個體驗：新增巷口四格漫畫、對開支票本、台中聲音明信片；既有沾福氣／你是哪一味保留。thanks與machine仍為soon。本輪改為乾淨留白藍色版型，新三站以hub路由共用底座。實作與開源元件限制請見根目錄README。

**現有視覺被使用者評為不夠有質感，請重新設計；不是要照著現有畫面微調，也不代表設計已驗收。**

方向已確認：用好玩的方式承載政策，不能取消互動、改成純政策文章，也不能只在遊戲結尾附上一段無關的政見。

## 保留的產品方向

- 江啟臣／國民黨藍色識別；目前主色 `#1A63C8`。具體排版、圖像、材質與互動視覺可重做。
- 沾福氣：長按或無障礙點按 → 日常心願 → 翻卡揭曉同一心願對應的政策 → 下載／分享。
- 你是哪一味：三個小選擇，中間穿插可開關冷氣的市場示意，再揭曉市場冷氣政策。所有玩家看同一市場場景，不推論政治立場。
- 好玩應來自可理解的操作與回饋，避免泛用插畫、空泛文案與機械式整頁染藍。
- 保留手機優先、大字模式、鍵盤操作、減少動態支援。

## 政策與資料邊界

原本兩體驗採以下兩項官網原文；新三體驗另外使用各路由資料檔中列明的公開政策ID：

- `TRA-06`：打造全齡友善人本道路。
- `IND-19`：公有市場裝冷氣，打造特色市場。

原文在 `packages/policy-data/src/policies.json`，情境及解釋在 `packages/experience/src/policy.ts`（以上路徑相對 `platform/`）。已收錄 117 項標題，不表示已全數接入遊戲或獲人工簽核。新增／修改政策請先核對公開來源，勿捏造預算、期程、施行狀態或降溫效果。

每個完整互動及匯出圖卡保留：政策來源、概念示意／非實測結果、政見／非施政成果、非官方與未獲團隊授權或背書。不得把測驗結果轉成政治支持度推論。

## 工程入口

從 repo 根目錄先 `cd platform`，依 `README.md` 指令安裝、測試與建置。完整套件與驗證指令見 `platform/README.md`。

- `apps/`：三個 Next.js 站點。
- `packages/ui/`：共用介面、政策互動與 CSS。
- `packages/experience/`：趣味結果、規則與政策映射。
- `packages/share-card/`：瀏覽器本機 SVG／PNG 圖卡，不上傳暱稱與作答。
- `scripts/serve.ts`：將三站靜態輸出聚合至同一個 loopback 預覽。
- `tests/`：原始計分、分享／隱私、來源、互動契約等回歸測試。

功能測試、TypeScript 與三個 app 建置需重新執行驗證；這只代表工程檢查，不代表美術品質、真人好玩程度、官方授權或實體 LINE 已驗收。改動後請重新執行。

視覺重做可能需要同步更新靜態樣式契約，但不得單純刪除隱私、來源、操作與計分測試來讓檢查變綠。

## 協作與交付

Fork → 建立分支 → 修改 → 測試與手機版截圖 → Pull Request。PR 請附主要狀態與實際下載圖卡，並清楚說明還沒實作的項目。

`platform/artifacts/` 是本機重建驗收資料，預設不追蹤；請勿提交含絕對主機路徑、私人輸入、內部紀錄或憑證的檔案。公開此 repo 不會自動部署正式網站。
