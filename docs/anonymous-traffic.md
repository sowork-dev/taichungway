# 匿名流量統計

本站只啟用第一方、無 Cookie 的彙總計次，不使用第三方分析服務。

## 指標口徑

- **每日瀏覽量**：瀏覽器載入一個允許統計的頁面，送出一個 `page_view`。重新整理或重新開啟會再計次，不是獨立訪客數。
- **熱門頁面**：按頁面代碼累加瀏覽量排序。
- **功能互動次數**：使用者在該頁首次主動點擊指定的開始／操作按鈕或送出聊天，計一個 `feature_use`。每次頁面載入最多一次，不是完成率、遊戲局數或政治支持度。
- 台北時區（Asia/Taipei）按日彙總；統計範圍為最近90天，寫入新資料時清理過期彙總。
- 不設訪客識別碼，無法提供不重複訪客、跨頁旅程、回訪率或個人偏好；不保證排除所有機器人。

## 隱私邊界

請求只允許 `{type,page}` 兩個欄位，頁面必須符合固定清單。不傳送或記錄 IP、裝置資訊、來源網址、網址查詢參數、聊天內容、測驗答案、心願、暱稱或任何私人文字。伺服器處理網路連線和既有防濫用時仍會短暫處理必要資訊，這與統計儲存分開。

Do Not Track / Global Privacy Control 會停止統計。QA 送出 `X-Analytics-Test: 1` 時只驗證請求，不寫入正式數字；測試不得以一般事件污染真實報表。

## 啟用與持久化

後端環境 `ANON_METRICS_ENABLED=1` 啟用，`ANON_METRICS_FILE` 指向靜態網站目錄以外的私有彙總 JSON。由 systemd StateDirectory 提供可寫目錄，不受每次 GitHub main 更新、建置或版本切換影響。未明確啟用時不收集。

公開的 `POST /api/metrics` 僅收集計次，沒有公開查詢統計的 GET API 或管理頁。由有伺服器權限的管理者讀取彙總檔，再依日期加總與輸出報表，不能用即時遊戲在線人數代替網站流量。

生產打包器在所有有效 HTML 中加入同源 `anonymous-metrics.js`，於加入後重新計算公開 manifest 與 CSP hashes。更新前端時必須保留這個打包步驟。nginx 僅把 `/api/metrics` 轉送到既有後端，限制512bytes，並保持存取日誌關閉。

## 驗收

1. 公開版本 SHA 與預期 main 相符，HTML 只包含一個同源統計 script。
2. 真實瀏覽器觸發 page_view 與首次互動；攔截請求加 QA 標頭，不寫入正式數字。
3. 檢查請求只有類型和頁面代碼，不含私人文字、來源或網址參數。
4. 驗證 DNT/GPC 不送出；跨站、非法欄位和查詢參數拒絕；統計檔無法公開存取。
5. 私有儲存的原子寫入、並發、重啟續計、日期換日和過期清理以檔案／HTTP測試驗證。
6. 只有從啟用後才有數據，過去流量不得補造。
