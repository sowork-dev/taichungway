# 啟臣，聊一下 · Taichung Way

手機優先的城市政策探索與雙人 PK：原創 Q 版角色、五個主題街區、15 個生活任務、完整提供文件與來源可追溯的政策問答。

**體驗網站：https://taichungway.sowork.ai**

> 本專案是獨立製作的 AI 分身介面原型，非江啟臣本人即時回覆，不代表本人、競選團隊或立法院授權／背書。
> **目前沒有接入生成式 AI**；自由輸入會依關鍵字檢索已收錄的公開資料卡，不是全領域對話或經本人訓練的模型。

## 包含功能

- 原創城市情境與可操作的 Q 版角色：手機搖桿、點地移動、快走與地標任務。
- **五區城市、15 任務**：3000 × 1800 的連續情境世界，鏡頭跟隨角色；生活照顧、創新產業、文化共好、山海永續與城市連結，不是只放大原本小圖。
- **完整提供文件**：匯入 ZIP 的 15 個政策主題、階段、標籤、支柱說明與逐條內容，每個任務可打開對應文件卡。
- **真人雙人 PK**：開房、六碼房號與連結邀請、網友配對、同房角色位置同步；沒有 AI 假玩家。
- **五題競速與再戰**：雙方準備後開賽，伺服器計時與計分，兩人作答或逾時後才揭曉答案和來源。PK 比文件理解，不比政治立場。
- 選擇真實公開政見作為政策技能卡，觀看作用機制示意，再追問成本、時程與適用條件。
- 理解進度僅存在本次頁面，不代表支持度或投票意向；動畫不冒充成效模擬。
- 手機首頁、分類與搜尋、政策詳情、來源清單與可分享連結。
- 對話式資料卡檢索；未收錄的立場不推測、不代言。
- 明確區分競選主張、公開人物資料與已實施政策。
- 不要求登入、不呼叫模型 API、不將輸入問題上傳；對話只存在本次頁面的記憶中。

## 快速啟動

```sh
git clone https://github.com/sowork-dev/taichungway.git
cd taichungway
npm start
```

需要 Node.js 22 以上；以瀏覽器開啟 `http://127.0.0.1:8765`。不需要外部 Node 套件、API Key 或資料庫。開兩個獨立瀏覽器 context，可測試真實兩端房間同步；自動化測試不等於真人驗收。本機預設只綁定 loopback，不會自動對外公開。

## 專案結構

```text
public/       可直接託管的網頁、SVG 人偶、檢索引擎及政策資料
server/       Node.js 雙人房間 API
data/         政策資料的維護來源
scripts/      明確指定 ZIP 的文件匯入器
 tests/       Node.js 單元測試與 Playwright 瀏覽器驗收
 docs/        資料與公開版本邊界說明
```

## 測試

```sh
npm test
```

瀏覽器測試及本機服務設定請見 [SETUP.md](SETUP.md)。測試涵蓋政策檢索與任務狀態機，以及手機版面、所有資料卡、來源、未知問題、隱私與錯誤狀態。另以 `python tests/quest_browser_qa.py http://127.0.0.1:8765` 回歸原始三個關卡，以 `tests/world_browser_qa.py` 驗收全部 15 任務與五個街區，以 `tests/pk_browser_qa.py` 驗收兩個獨立瀏覽器 context 的真實房間、五題、計分、再戰與離房。

## 資料與限制

保留原本 12 筆公開來源資料，並匯入完整 `taichung-machine-site.zip` 的首頁＋15 個政策子頁。來源版本與逐項保留數量見 [文件覆蓋說明](docs/policy-source-coverage.md)。提供文件標示為「提供文件主張、待獨立核實」；匯入日不等於政策發布日或實施日，沒有持續自動更新。原始 ZIP、HTML 與第三方圖像不放入公開 repo。

來源包含候選人公開政策網站與立法院公開人物頁。政見不代表已立法、編列預算、施工或開放申請；金額、資格與進度仍須查主管機關。資料整理不構成任何單位的背書。

修改資料時同步更新 `data/knowledge.json` 與 `public/knowledge.json`，詳見 [data/README.md](data/README.md)。

## 隱私與安全

不使用 Cookies、localStorage、追蹤分析或永久戰績。自由政策提問不上傳。只有主動加入多人 PK 後，暱稱、房號、位置、選項與分數才會送至伺服器，僅暫存記憶並逾時清除；token 不放分享網址，重新整理會失去該頁房間身分。請勿用真名或聯絡資料。持有邀請連結的人可能加入房間。角色位置同步僅供視覺互動，並非防外掛物理引擎。API 規格見 [multiplayer-api.md](docs/multiplayer-api.md)。託管平台連線紀錄須另行配置；這不是陳情或補助申請入口。

公開版本不含內部部署、主機設定、SSH 金鑰或憑證；請見 [公開範圍](docs/sanitization-policy.md) 與 [SECURITY.md](SECURITY.md)。
